# 1.3.0

- Find duplicates (Settings → General): scans every photo and groups copies of the same picture by what it shows, whatever the file is called, however large or compressed.
- Exact, Close and Loose choose how alike two photos must be.
- The best copy of each set is kept and the rest are marked; tap to change, hold to see one large, then delete the marked ones to the trash (with undo).
- The first scan reads every photo once and takes a while; later scans only read new ones.
